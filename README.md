## Global Economic Indicators: Data Collection and Integration

## Project Overview

This project focuses on collecting and integrating 20 macroeconomic indicators from the World Bank API into a structured dataset covering multiple countries and years. The resulting dataset is exported in CSV format for further analysis and visualization.

## Project Objectives

- Collect 20 macroeconomic indicators from the World Bank API.
- Integrate indicator datasets using country codes and years.
- Organize the data into a structured dataset.
- Export the consolidated dataset in CSV format for further use.

## Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Requests
- World Bank API

## Workflow

1. Retrieve country metadata from the World Bank API.
2. Retrieve data for 20 macroeconomic indicators.
3. Merge indicator datasets based on country codes and years.
4. Export the consolidated dataset in CSV format.

## Data Source

World Bank Open Data API: https://api.worldbank.org/

The data is sourced from the World Bank. Data availability may vary across countries, indicators, and years.

## Project Deliverables

- Python notebook for data collection and integration.
- Consolidated macroeconomic dataset in CSV format.
